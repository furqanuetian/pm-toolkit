# Communication Plan

**Purpose:** Define how project information will be shared, with whom, and at what frequency.

**Version:** 1.0
**Last Updated:** [YYYY-MM-DD]

---

## Communication Objectives

- Keep stakeholders informed of progress and changes.
- Support timely decision-making with accurate information.
- Escalate risks and issues early and clearly.
- Promote transparency and collaboration across teams.

---

## Communication Matrix

| Stakeholder / Group | Communication Type | Format | Frequency | Owner | Delivery Method |
|---------------------|-------------------|--------|-----------|-------|-----------------|
| Project Sponsor | Executive Status Report | Written | Monthly | Project Manager | Email / Dashboard |
| Stakeholders | Project Status Report | Written | Bi-Weekly | Project Manager | Email / Dashboard |
| Client / Customer | Release Update | Written | Per Release | Project Manager | Email / Dashboard |
| Vendors / Suppliers | Procurement / Status Update | Meeting / Email | Weekly | Project Manager | Virtual |
| Core Team | Team Sync | Meeting | Weekly | Project Manager | In-person / Virtual |
| Cross-Functional Teams | Integration Update | Meeting / Email | Per Sprint | Tech Lead | Virtual |

---

## Meeting Cadence

| Meeting | Frequency | Duration | Attendees | Owner |
|---------|-----------|----------|-----------|-------|
| Daily Standup | Daily | 15 min | Scrum Team | Scrum Master |
| Sprint Planning | Per Sprint | 2-4 hours | Scrum Team | Scrum Master |
| Sprint Review | Per Sprint | 1-2 hours | Scrum Team + Stakeholders | Scrum Master |
| Sprint Retrospective | Per Sprint | 1 hour | Scrum Team | Scrum Master |
| Backlog Refinement | Per Sprint | 1 hour | Product Owner + Developers | Product Owner |
| Weekly Sync | Weekly | 30 min | Core Team | Project Manager |
| Steering Committee | Monthly | 1 hour | Sponsor + Leadership | Project Manager |

## Reporting

| Report | Audience | Frequency | Owner |
|--------|----------|-----------|-------|
| Status Report | Stakeholders | Weekly | Project Manager |
| Executive Summary | Sponsor | Monthly | Project Manager |
| RAID Log Review | Core Team | Weekly | Project Manager |
| Sprint Dashboard | Team + Stakeholders | Per Sprint | Project Manager / Scrum Master |

## Escalation Paths

| Issue Type | First Contact | Second Contact | Third Contact |
|------------|---------------|----------------|---------------|
| Technical risk | Tech Lead | Engineering Manager | CTO |
| Schedule delay | Project Manager | Program Manager | VP Engineering |
| Budget overrun | Project Manager | Finance | Sponsor |
| Resource constraint | Project Manager | Engineering Manager | VP Engineering |
| Client / stakeholder issue | Project Manager | Sponsor | Leadership |
| Compliance / regulatory | Compliance Lead | QA Manager | General Counsel |

## Communication Guidelines

- Keep communication timely and actionable.
- Tailor communication to the audience (level of detail, format).
- Highlight risks, decisions, and blockers early.
- Record action items and owners for follow-up.

---

## Review Guidance

Review and update this plan:

- During project kickoff
- After major scope changes
- When new stakeholders join
- When communication issues arise
- At key project milestones
